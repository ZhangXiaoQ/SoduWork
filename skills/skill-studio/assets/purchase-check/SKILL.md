# 采购需求核验

读取用户指定的采购需求和报价材料，按 [核验规则](references/rules.md) 逐项检查。

1. 确认材料范围；缺少文件时列出文件名和用途，不猜测价格或库存。
2. 整理物料、规格、数量、单位、交期和报价来源，保留来源定位。
3. 输出各项完整/缺失/冲突状态，并将判断关联到报价中的字段或来源位置；单位不一致或报价过期时明确标记。
4. 报价未提供的税费、运输、安装或交付范围标记为信息不足，不从其他字段或常见做法推断。交期不等于指定楼层配送，安装也不自动代表运输已包含。
5. 生成采购核验报告.md，包含结论、核验表、缺项清单和需要人确认的问题。涉及金额时列明计算式，并区分已知小计与口径完整的总价。
6. 不调用下单或支付接口；用户确认资料完整后也只交付报告。

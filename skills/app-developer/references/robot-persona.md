# 角色与持续工作

目标：繁琐工作自动完成，有辨识度的角色交付结果。角色不是换个昵称的通用聊天框。

角色卡：名字 / 单个角色形象 / 性格3词 / 职责 / 输入 / 触发 / 输出 / 边界。写进随包业务技能；手动与计划共用同一角色、方法和数据。图标主体配色按角色选择，背景遵守 [icon-design.md](icon-design.md)，禁止多色/紫色渐变底板；不强制灰色版或家族套装。

示例：阿奇＝好奇、跳跃、鼓励（灵感扭蛋机）；辩辩＝敏锐、坦诚、建设性（脑洞辩论员）；小尾＝细心、温柔、利落（下班收尾官）；小纪＝清楚、直接、可靠（会议行动员）；阿巡＝沉稳、克制、警觉（项目哨兵）。

界面：角色头像、第一人称介绍、业务动作、订阅节奏、成果回看。用“阿奇每天来点新想法”“交给小纪整理”，不把调度术语当角色文案。底层 automation、MCP、ID 与权限契约不改名。

输出：先给完成结果，再用角色语气简短表达；结论 / 下一步 / 必要证据。温暖不啰嗦，不重复自我介绍，不虚构陪伴、进度、见闻或已完成动作。失败说清原因与下一步；无变化安静，有重要结果才提醒。

技能：处理真实输入→校验→按 revision 保存结构化结果→读取确认。成果保存角色名、时间、来源 ID、正文；同一次触发保持幂等。角色语气不能覆盖用户要求、账号隔离或真实业务权限。

# 设计与质量

目标：最好的创意与设计；先进且可运行的技术；美观、精致、操作简洁、打开即用。

页面只要求中英文适配；默认只做一个与题材匹配的完整视觉主题，不强制亮色/暗色双模式或主题切换按钮。用户明确要求时再做双模式。图标的明暗背景辨识检查不等于开发两套页面。

先定：用户/场景/核心动作/信息层级/风格/反馈。游戏按题材选炫酷、沉浸、童趣、治愈等；工具强调效率；不统一套极简模板。

设计前查 GitHub 同类优秀项目：维护、复用边界、技术适配、许可；记录真实链接和采用点。简单本地即用用原生 JS 分模块、直接挂载容器，详见 [local-app-structure.md](local-app-structure.md)；Web 服务/H5 可用 Vue、React 等，不受宿主原生 JS 技术栈限制。

视觉网站查询可选；查询则看最新、匹配即用类型。Awwwards、Mobbin、优秀产品官网仅为示例，不限站点。记录来源/参考点，未查询不虚构出处。

即用只做一个专属图标，可用单色标志或彩色实体：业务隐喻、主体饱满、小尺寸清晰。默认透明底/白底/纯色底；禁止多色渐变背景、紫色渐变和紫色发光底板，确需渐变仅用非紫色同色系明暗变化，不用“彩色”要求强加底板。详见 [icon-design.md](icon-design.md)。灰色线条版与整套图标不作为必交项。

作品：有辨识度的信息层级、字体、留白、配色与交互；避免模板化渐变、大圆角卡片堆叠、无意义装饰和空泛文案。尊重既有设计系统，技术兼顾成熟度、性能、可访问性与维护成本；脚手架不能直接作为设计成品。

质量：真实内容/操作/错误/空态/加载态；键盘、焦点、窄窗口、中英文；不做假按钮或假成功。少量动画服务操作反馈，hover 不移动盒子。

验收：安装→首次打开→核心操作→AI→写回→刷新→关闭重开→计划无窗口执行→版本升级。截图和报告标明版本、环境、实测范围；静态检查不等于运行或设计通过。

# 单个即用图标

默认：只做当前即用的一个专属图标，可单色或彩色；不是侧边栏家族、整套图标或配色展示板。黑白标志也可以作为成品，不为“彩色”而加背景。

思路：核心用途/角色 → 一个直观隐喻 → 圆润实体 → 少量叠层 → 小尺寸辨识。精致、亲和、有记忆点；避免通用四宫格、细碎装饰、厚重3D。

形体：正方形画幅；光学居中、饱满、不窄；控制两侧留白；圆角与层次协调；主体轮廓一眼可认。饱满通过主体占比实现，不强加铺满画幅的圆角彩色底板。

主体颜色：按业务、角色、题材选择，主色＋少量辅助色；可用彩色实体或简洁黑白标志。少量紫色主体细节不等于允许紫色底板，不靠复杂阴影维持辨识。

背景硬约束（2026-11-05 用户偏好）：默认透明底、白底或克制的纯色底。禁止彩虹、跨色相/多色渐变背景；尤其禁止紫色渐变、蓝紫/紫粉渐变及霓虹紫光晕，避免通用AI风格的紫色底板。确需渐变背景时，只允许非紫色的同一色系明暗变化，幅度轻微，不混入另一色相；不以“柔和高光”绕过此规则。

生成提示必须携带上述背景约束。正例：白底黑色业务标志、透明底彩色实体、白底蓝色文件夹、浅蓝到稍深蓝的同色系背景（确有必要时）。反例：蓝→紫、紫→粉、紫→橙渐变底、紫色发光圆角底板。主体多色可以，背景不能借主体配色变成多色渐变。

自检：16/24/32/48/128px、白/灰/黑背景；缩小不糊、不挤、无多余底板。单独检查背景：若出现紫色渐变、跨色相渐变或霓虹光晕，重新设计背景后再交付。参考图用于提炼方法，不机械复制构图或固定配色。

交付：顶层 icon＝内嵌 PNG，≤256px、≤96KB；保留透明背景及必要边缘间距；SVG 源文件可随包。默认不生成灰色线条版、不扩成一整套；用户明确要求时再扩展。
